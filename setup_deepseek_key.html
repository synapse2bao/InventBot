🔑 DeepSeek API KEY 配置

请配置您的 DeepSeek API KEY 以使用完整功能

📖 如何获取 DeepSeek API KEY

  1. 访问 DeepSeek 官网
  2. 注册新账户或登录现有账户
  3. 进入 API 管理 页面
  4. 点击 创建新的 API KEY
  5. 复制生成的 API KEY
  6. 将 API KEY 粘贴到下方输入框中
点击下方按钮自动更新项目根目录的 .env 文件： 

            
        

        
        

            注意：API KEY 将保存到本地 .env 文件中，请妥善保管。如果 API KEY 无效，系统会在启动时提示重新配置。
