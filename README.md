# InventBot - AI驱动的TRIZ创新问题解决系统

一个基于TRIZ（发明问题解决理论）的AI辅助创新问题解决系统，支持硬件和软件矛盾分析、科学效应应用、发明原则推荐等功能。

## ✨ 功能特性

- 🤖 **模型支持**：支持 DeepSeek 模型
- 🔍 **智能矛盾识别**：自动识别硬件矛盾和软件矛盾
- 📊 **矛盾矩阵**：支持39×39硬件矛盾矩阵和24×24软件矛盾矩阵
- 🧪 **科学效应应用**：基于科学效应库生成解决方案
- 📚 **发明原则推荐**：根据矛盾类型推荐40个TRIZ发明原则
- 💾 **数据库存储**：使用SQLite存储发明原则和科学效应数据
- 🌐 **Web界面**：现代化的Web界面，支持实时对话和进度显示

## 📋 系统要求

- Python 3.8 或更高版本
- Windows 10/11（批处理文件为Windows设计）
- 至少 2GB 可用内存
- 网络连接（用于调用AI模型API）

## 🚀 快速开始

### 1. 克隆或下载项目

```bash
git clone https://github.com/yourusername/inventbot.git
cd inventbot
```

### 2. 安装依赖

```bash
pip install -r requirements.txt
```

### 3. 配置API密钥

#### 方法一：使用配置向导（推荐）

1. 运行 `启动后端.bat`
2. 如果未配置API密钥，系统会自动打开配置页面
3. 输入您的 DeepSeek API KEY 并验证
4. 点击"更新 .env 文件"按钮自动保存

#### 方法二：手动配置

在项目根目录创建 `.env` 文件，添加以下内容：

```env
DEEPSEEK_API_KEY=your_deepseek_api_key_here
```

### 4. 启动服务

#### Windows用户

直接双击运行 `启动后端.bat`

#### 其他系统

```bash
python app.py
```

### 5. 访问Web界面

打开浏览器访问：`http://127.0.0.1:5000`

## 📖 使用指南

### 基本使用流程

1. **选择AI模型**
   - 在页面顶部选择要使用的AI模型（DeepSeek Chat 或 Reasoner）

2. **描述问题**
   - 在输入框中描述您要解决的创新问题
   - 系统会自动识别问题类型

3. **矛盾识别**
   - 系统会自动识别硬件矛盾或软件矛盾
   - 提取改善参数和恶化参数

4. **解决方案生成**
   - 系统根据矛盾类型推荐相应的发明原则
   - 应用科学效应生成具体解决方案
   - 显示详细的解决步骤和进度

5. **查看结果**
   - 查看AI生成的完整解决方案
   - 可以复制解决方案内容
   - 查看使用的AI模型信息

### 功能说明

#### 硬件矛盾

当系统识别为硬件矛盾时：
- 使用39×39硬件矛盾矩阵
- 从39个硬件参数中选择改善和恶化参数
- 推荐相应的发明原则（1-40号）

#### 软件矛盾

当系统识别为软件矛盾时：
- 使用24×24软件矛盾矩阵
- 从24个软件参数中选择改善和恶化参数
- 推荐相应的发明原则（1-40号）

#### 科学效应应用

- 系统会根据问题描述提取功能需求
- 从科学效应数据库中匹配相关科学效应
- 当科学效应数量≤30时，使用完整描述生成解决方案
- 当科学效应数量>30时，仅使用名称生成解决方案

## ⚠️ 注意事项

1. **API密钥安全**：请妥善保管您的API密钥，不要将其提交到版本控制系统

## 🐛 故障排除

### 后端启动失败

1. 检查Python版本：`python --version`（需要3.8+）
2. 检查依赖安装：`pip install -r requirements.txt`
3. 检查端口占用：确保5000端口未被占用
4. 查看错误日志：检查控制台输出的错误信息

### API密钥验证失败

1. 检查 `.env` 文件是否存在且格式正确
2. 确认API密钥没有多余的空格或引号
3. 验证API密钥是否有效（访问对应平台检查）


### 前端无法连接后端

1. 确认后端服务正在运行
2. 检查浏览器控制台是否有错误
3. 确认访问地址为 `http://127.0.0.1:5000`
